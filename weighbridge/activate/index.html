Activate your license

A new installation asks for a license key before anything else.

The first time you open Weighbridge, it shows the Activate Weighbridge screen.

#Steps

  1. Copy the license key Mochan Labs sent you.
  2. Paste it into License key and press Activate.
  3. The app checks the key with the Mochan Labs license server and opens the sign-in screen.

Activation needs internet. A key works on only as many computers as it was issued for. If activation fails, the screen tells you why (wrong key, key already used on its maximum number of computers, or no internet).

#After activation

  • The computer re-checks the license with the server every few hours in the background.
  • If the internet is down, the app keeps working for a grace period set on your license, normally 7 days. Once the computer reaches the server again, the clock resets.
  • If the grace period runs out, or the license has expired, the activation screen returns until the license is renewed. See License renewal and expiry notices.
Tip

Moving to a new computer? Ask Mochan Labs to release the old one first, or the key will count against both.

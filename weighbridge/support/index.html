Get help

Who to contact and what to send so we can help quickly.

Mochan Labs

  • Email: mochanlabs@gmail.com
  • Website: mochanlabs.com

#Before you write

Check Fix common problems. Most problems are on that page.

#What to send

  1. What you were doing and what you expected.
  2. What happened, with a screenshot if you can.
  3. The version (Administration → About).
  4. The computer's ID from Administration → License, if it's about the license.
  5. For a crash or a blank screen, the newest file from %LOCALAPPDATA%\Weighbridge\logs.
Note

Please don't send passwords, license keys or the whole database by email. If we need data, we'll agree a safe way to share it.

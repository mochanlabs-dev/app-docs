---

Open **Masters → Materials**.

![Materials](/img/materials.png "Each material has a rate, an HSN code and a GST %.")

| Column | Meaning |
|---|---|
| **Code**, **Name** | What operators pick on the Token page. |
| **Rate** | The standard rate per unit. Parties can have their own ([Parties and party rates](/parties/)). |
| **HSN code** | The tax classification printed on the invoice. |
| **GST %** | Applied to the taxable amount of every sale of this material. |

Press **Add** to create a material, or the edit icon to change one.

:::note
GST is **taken from the material**, not typed on each bill. Set it correctly once. A change affects new bills only.
:::
